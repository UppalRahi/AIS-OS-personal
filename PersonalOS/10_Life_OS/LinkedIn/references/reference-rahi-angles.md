# Rahi LinkedIn Topic Bank

Map posts to real experience. **Never invent results. Never flex clients.**

## Content pillars (non-salesy)

| Pillar | What it sounds like | Example angle |
|--------|---------------------|---------------|
| **Noticing** | Observation from inside the work | "The friction isn't leads. It's the pre-work." |
| **Learning** | Something you got wrong, then refined | "I tried to automate everything. Narrower worked." |
| **Thinking** | Framework applied honestly | "Eliminate before you automate. Still learning this." |
| **Becoming** | Engineer → systems builder arc | "I think in workflows before I find the words." |
| **Questioning** | Genuine curiosity, invites reply | "What eats your morning before the real work?" |

## What to pull from (internal only — don't name in posts)

- Debugging enrichment pipelines, webhook failures, list hygiene
- Obsidian AIOS as thinking system (meta, not product pitch)
- Introvert articulation gap — finding language for systems thinking
- EAD mindset: eliminate copy-paste before adding tools
- NIT / Kashmir / startup arc — only when tied to a lesson, not for sympathy points

## Avoid (unless Rahi explicitly requests)

- Client case studies with names, revenue, timelines
- Tool-stack listicles ("11 APIs for GTM")
- Comment-for-template CTAs
- Headline-style proof stacking in post openers

## Headline options (profile, not post)

**Level 2:** I help B2B startups scale outbound with n8n + Smartlead pipelines

**Level 3 (when ready):** Building GTM systems that run quietly in the background | n8n, APIs, automation

## CTAs (default: one only)

- Open question (preferred): "What's the small task that eats your morning?"
- Reflection invite: "Curious if others see this too."
- No CTA is also fine for pure observation posts.

## Visual pairing

| Post type | Visual |
|-----------|--------|
| Reflective / noticing | Text-only, or simple photo (desk, notebook, walk) |
| Light framework | Hand-drawn diagram, not polished sales infographic |
| Rare technical share | Blurred workflow screenshot, no client data |
