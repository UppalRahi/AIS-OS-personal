## 3. The weekly /level-up check

Run these questions to find opportunities for automation:

### **Mindset Check (Opportunities)**
- What did I do 3+ times manually this week? (e.g. data copy-pasting, report building)
- What felt like "smart intern work" that can be delegated to an AI assistant?
- If 500 new clients signed up today, what operational bottleneck would break first?

### **Method Check (Scoping)**
- **Eliminate**: If we stop doing this task entirely, does anything break?
- **Automate**: How can we apply the 60/30/10 rule (60% deterministic, 30% AI, 10% manual)?
- **Delegate**: If too complex, who or what system gets it?
- **Autonomy Level**: L1 (AI suggests), L2 (AI drafts), L3 (AI runs with supervision), L4 (Autonomous).
- **KPI**: What metric does this improve (more customers, more value per customer, less cost)?

### **Machine Check (Execution)**
- Should this be a **Prompt template**, a **Deterministic script**, an **AI-assisted skill**, or a **Sub-agent**?
- Write down the automation draft in `decisions/log.md`.
